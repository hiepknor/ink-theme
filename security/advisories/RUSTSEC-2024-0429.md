# RUSTSEC-2024-0429 downstream remediation

Status: patched downstream  
Owner: Ink maintainers  
Review deadline: 2026-11-08

## Exposure

The Tauri Linux integration resolves `glib 0.18.5` through WebKitGTK. The
affected `VariantStrIter` implementation can dereference a null pointer in an
optimized build because a C out-argument was passed through an immutable
reference.

The design-system packages do not ship Rust or Tauri. Exposure is limited to
the Linux desktop integration, but the defect is treated as applicable because
it exists in a runtime dependency.

## Remediation

`vendor/glib-0.18.5-ink1` is the crates.io source for `glib 0.18.5` with the
upstream fix from gtk-rs/gtk-rs-core#1343 backported: the pointer is declared
mutable and passed as `&mut p`. Cargo resolves that local source through
`[patch.crates-io]`.

CI verifies the patch structure, checks the locked Rust graph, runs RustSec and
cargo-deny, and compiles the Tauri integration. RustSec's version-based match is
explicitly ignored only after the structural patch check succeeds.

## Removal condition

Remove the vendored crate, Cargo patch, advisory exception and this record as
soon as the Tauri/WebKitGTK dependency graph resolves a patched upstream glib
release. CI intentionally fails when `glib 0.18.5` disappears while the patch
remains.
